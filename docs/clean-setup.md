# Guided setup / הקמה מודרכת

## עברית

1. האפליקציה מציגה בכל פעם את ההרשאה החסרה: מיקרופון והתראות, ואז חיבור רכיב ההקלטה עם צימוד. פעלו לפי ההדרכה לפתיחת אפשרויות המפתח, ניפוי באגים אלחוטי והזנת קוד הצימוד של Android. האפליקציה אינה מאשרת הרשאות במקומכם.
2. אם התקנה קודמת השתמשה בניסוי הנגישות, לחצו **חזרה לחיבור השיחות** ואשרו כשאין שיחה או הקלטה פעילה. ההקלטות והצימוד הקיים נשמרים. הקלטה אוטומטית תכובה עד שתפעילו אותה בנפרד.
3. לאחר שרכיב ההקלטה מחובר, אפשר להמשיך לאישור זיהוי שיחות ולהפעלת הקלטה אוטומטית, או לסיים ידנית. חיבור אינו מפעיל הקלטה. במסך הראשי בחרו **שיחת WhatsApp** להקלטת שיחה; **מיקרופון** מיועד להקלטה רגילה.
4. בצעו שיחת בדיקה בידיעת המשתתף והאזינו לקובץ כדי לוודא ששני הצדדים נשמעים. יש לבדוק כל מכשיר ואופן שימוש, כולל אוזניות. חיבור פעיל או קובץ שנשמר אינם הוכחה להקלטת שני הצדדים. אחרי אתחול השתמשו ב[הדרכת ההפעלה](offline-recovery-setup.md).
5. ההגדרות נקיות: מצב החיבור בראש המסך; הקלטה אוטומטית, גיבויים ל־Drive/Telegram, שמות ושפה נפתחים בלחיצה. כל משתמש מחבר את החשבונות שלו.

מסלול הנגישות הניסיוני אינו מוצע בגרסה הנוכחית. ניתן לקרוא את [מגבלות הניסוי ההיסטורי](no-pairing-experiment.md). בדיקת המצב אינה משנה מסלול או מפעילה הקלטה.

## English

1. Setup presents one missing approval at a time: microphone and visible notifications, then the paired phone connection. Follow the guidance to Developer options, Wireless debugging and Android's pairing code. The app cannot grant Android approval for you.
2. If an older installation selected the accessibility experiment, choose **Return to call connection** and confirm while no call or recording is active. Recordings and existing pairing are kept. Automatic mode is disarmed until you separately enable it again.
3. Once the component connects, continue to call detection and separately opt into automatic recording, or finish manually. Pairing and activation never start capture. On the recording screen choose **WhatsApp call** for calls; **Microphone** is for ordinary voice notes.
4. Run a disclosed test call and listen to check both participants on each phone and actual speaker/earpiece/headset route. Readiness and a saved file do not establish intelligible two-party audio. After reboot follow [recovery instructions](offline-recovery-setup.md).
5. Settings shows connection status first; tap Auto, backups, names or language to open their controls. Each user independently connects and enables their own Drive/Telegram accounts.

The accessibility experiment is no longer offered in the current app; see its [historical limitations](no-pairing-experiment.md). Observing or refreshing an installation never changes recording mode or arms recording.
